## Question and authorized implementation

Test whether current-row sampling of selected FFN weight gradients can reduce
charged time to a fixed held-out target on the specified FP32 MPS byte language
model, with a common-budget endpoint quality guard. A blocked/negative result
with correct code and evidence completes this scope. No broader accelerator,
optimizer, model, memory-saving or mathematical acceptance claim is permitted.

Implement independently with native Torch. For flattened X,D, n>0,
G=D.T@X, a_i=norm(D_i)*norm(X_i), p_i=.9*a_i/sum(a)+.1/n. Draw k iid rows
with replacement, retaining duplicates and using the same indices in X and D.
Return sum(D_i.T X_i/(k p_i)); do not divide by n again. Production
k=max(1,ceil(rho*n)), rho in {1/8,1/4,1/2}, fixed across layers/steps.
k>=n dispatches directly to native F.linear outside custom autograd.
Forward, input and bias derivatives are exact. No parameters change before
the entire effective-batch backward completes. Native AdamW consumes actual
dense gradient tensors, including zeros; no preview, audit, rejection or replay.

Compute detached device FP32 scores after separately scaling X and D by their
maximum absolute values. Verify finite scales. Only a proved zero *unscaled*
entire X or D allows zero dW without sampling. Nonzero operands with zero,
invalid or nonfinite score sum abort. In particular reciprocal-scale rows
X=(1e30,1e-30), D=(1e-30,1e30) must abort, not return zero. Transfer only the
n-element scores to CPU FP64, normalize/validate the mixture there, use native
CPU torch.multinomial with the layer generator, and derive inverse-square-root
weights from the SAME FP64 probabilities. Transfer indices and cast weights;
gather, split-scale, and use a smaller dense GEMM. No full-n masked GEMM,
n-by-n sketch, per-row outer product stack, custom CDF or device kernel.
Uniform uses direct CPU randint and constant n/k, with no score work.

Support FP32 CPU/MPS and explicit CPU FP64 reference fixtures; reject AMP,
other dtypes, higher derivatives and sampled shared/tied weights. Each sampled
weight has one module owner; every unique optimizer parameter occurs once.
The native embedding/output tie remains exact. Accumulation weights each
microbatch loss by its valid-target fraction, with independent local draws.

Named seeds are SHA256 of ASCII compact JSON [base_seed,domain,*ids], first
eight bytes big endian modulo 2**63-1. Domains: init,data,sampling,order.
Each layer/sampler has a dedicated CPU generator; IDs block0.ffn_in/out through
block3. Exact and proved-zero paths consume no draws. Record seeds and states.

# SPDX-License-Identifier: AGPL-3.0-only
"""Fixed-budget row sampling of dense weight gradients, with exact dX/db.

The caller weights losses before backward, excludes shared sampled parameters,
checks every model gradient before optimizer.step, and owns effective batches.
Exact dispatch is native F.linear (including its native differentiation policy).
Sampled backwards check their produced gradients and reject higher derivatives.
Dynamic shared-weight detection requires Torch's current-backward-task primitive;
no private optimizer/kernel implementation is used.
"""
from __future__ import annotations

import hashlib
import json
import math
import weakref
from dataclasses import dataclass, field
from typing import Iterable

import torch
from torch import Tensor, nn
from torch.nn import functional as F


def named_seed(base_seed: int, domain: str, *ids: str) -> int:
    """Resolve the prospective compact ASCII JSON SHA256 named stream."""
    if type(base_seed) is not int or not isinstance(domain, str) or any(not isinstance(i, str) for i in ids):
        raise ValueError('named seeds require integer base_seed and string domain/ids')
    encoded = json.dumps([base_seed, domain, *ids], separators=(',', ':'), ensure_ascii=True).encode('ascii')
    return int.from_bytes(hashlib.sha256(encoded).digest()[:8], 'big') % (2**63-1)


@dataclass
class SamplingState:
    base_seed: int
    layer_id: str
    sampler: str = 'importance'
    rho: float = .25
    seed: int = field(init=False)
    generator: torch.Generator = field(init=False, repr=False)

    def __post_init__(self):
        if self.sampler not in ('importance', 'uniform'):
            raise ValueError('sampler must be importance or uniform')
        if self.rho not in (.125, .25, .5, 1):
            raise ValueError('rho must be one of 1/8, 1/4, 1/2, 1')
        self.seed = named_seed(self.base_seed, 'sampling', self.layer_id, self.sampler)
        self.generator = torch.Generator(device='cpu').manual_seed(self.seed)

    def state_dict(self) -> dict:
        return {'base_seed': self.base_seed, 'layer_id': self.layer_id, 'sampler': self.sampler,
                'rho': self.rho, 'seed': self.seed, 'generator_state': self.generator.get_state().clone()}

    def load_state_dict(self, state: dict) -> None:
        for key in ('base_seed', 'layer_id', 'sampler', 'rho', 'seed'):
            if state.get(key) != getattr(self, key):
                raise ValueError(f'sampling state metadata mismatch: {key}')
        rng = state.get('generator_state')
        if not isinstance(rng, Tensor) or rng.device.type != 'cpu' or rng.dtype != torch.uint8:
            raise ValueError('generator_state must be a CPU byte tensor')
        self.generator.set_state(rng.clone())


def _finite(tensor: Tensor, name: str) -> None:
    if not bool(torch.isfinite(tensor).all()):
        raise RuntimeError(f'{name} must be finite')


def _operand_scales(x2: Tensor, d2: Tensor) -> tuple[Tensor, Tensor]:
    # Preserve CPU FP64 extreme reference scales until AFTER normalization.
    sx, sd = x2.detach().abs().amax(), d2.detach().abs().amax()
    _finite(sx, 'X scale')
    _finite(sd, 'D scale')
    return sx, sd


def importance_probabilities(x2: Tensor, d2: Tensor) -> Tensor | None:
    """CPU FP64 mixture probabilities; None only for proved unscaled zero.

    Only the n device FP32 scores move to CPU; complete operands stay on device.
    Nonzero operands whose normalized FP32 scores vanish are an explicit error.
    """
    if x2.ndim != 2 or d2.ndim != 2 or x2.shape[0] != d2.shape[0] or not x2.shape[0]:
        raise ValueError('score operands require matching nonempty row matrices')
    sx, sd = _operand_scales(x2, d2)
    if bool(sx == 0) or bool(sd == 0):
        return None
    xs = (x2.detach()/sx).to(dtype=torch.float32)
    ds = (d2.detach()/sd).to(dtype=torch.float32)
    scores = torch.linalg.vector_norm(xs, dim=1)*torch.linalg.vector_norm(ds, dim=1)
    _finite(scores, 'sampling scores')
    scores_cpu = scores.to(device='cpu', dtype=torch.float64)
    total = scores_cpu.sum()
    if not bool(torch.isfinite(total)) or not bool(total > 0):
        raise RuntimeError('nonzero operands produced invalid or zero sampling score sum')
    n = len(scores_cpu)
    p = .9*(scores_cpu/total)+.1/n
    if (not bool(torch.isfinite(p).all()) or not bool((p > 0).all())
            or abs(p.sum().item()-1) > 5e-15
            or p.min().item() < .1/n*(1-1e-12)):
        raise RuntimeError('invalid sampling probabilities')
    return p


def gather_weight_gradient(x2: Tensor, d2: Tensor, indices_cpu: Tensor,
                           probabilities_cpu: Tensor, k: int) -> Tensor:
    """Actual importance gather/split-inverse-scale/small-GEMM runtime path.

    Does not dispatch k>=n: enumeration deliberately exercises duplicates for
    any supplied k. Production exact dispatch happens in sampled_linear.
    """
    if type(k) is not int or k <= 0:
        raise ValueError('k must be a positive integer')
    n = x2.shape[0]
    if (indices_cpu.device.type != 'cpu' or indices_cpu.dtype != torch.int64
            or indices_cpu.shape != (k,) or probabilities_cpu.device.type != 'cpu'
            or probabilities_cpu.dtype != torch.float64 or probabilities_cpu.shape != (n,)):
        raise ValueError('gather requires CPU int64 indices and CPU FP64 probabilities')
    if bool((indices_cpu < 0).any()) or bool((indices_cpu >= n).any()):
        raise ValueError('sample index out of bounds')
    selected = probabilities_cpu.index_select(0, indices_cpu)
    if not bool(torch.isfinite(selected).all()) or not bool((selected > 0).all()):
        raise RuntimeError('sample probabilities must be positive and finite')
    weights_cpu = (k*selected).rsqrt()
    weights = weights_cpu.to(device=x2.device, dtype=x2.dtype)
    # The FP64 probabilities above also determine the inverse scales, with no
    # second normalization or independently rounded probability calculation.
    rows = indices_cpu.to(device=x2.device)
    xs = x2.index_select(0, rows)*weights[:, None]
    ds = d2.index_select(0, rows)*weights[:, None]
    dw = ds.T@xs
    _finite(dw, 'sampled dW')
    return dw


# One live weak reference and last graph-task ID per sampled weight; no graph
# or operand is retained. Different SamplingState objects cannot evade this.
_last_backward: dict[int, tuple[weakref.ReferenceType, int]] = {}


def _claim_backward(weight: Tensor) -> None:
    primitive = getattr(torch._C, '_current_graph_task_id', None)
    if primitive is None:
        raise RuntimeError('Torch current backward graph task primitive unavailable')
    task = primitive()
    if task < 0:
        raise RuntimeError('Torch current backward graph task primitive unsupported')
    key = id(weight)
    previous = _last_backward.get(key)
    if previous is not None and previous[0]() is weight and previous[1] == task:
        raise RuntimeError('same weight reused/shared in one sampled backward graph')
    def remove(ref, key=key):
        current = _last_backward.get(key)
        if current is not None and current[0] is ref:
            _last_backward.pop(key, None)
    _last_backward[key] = (weakref.ref(weight, remove), task)


class _SampledLinear(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, weight, bias, state, k):
        ctx.save_for_backward(x, weight)
        ctx.state, ctx.k, ctx.has_bias = state, k, bias is not None
        return F.linear(x, weight, bias)

    @staticmethod
    def backward(ctx, d):
        if torch.is_grad_enabled():
            raise RuntimeError('sampled_linear does not support higher-order differentiation')
        x, weight = ctx.saved_tensors
        x2, d2 = x.reshape(-1, weight.shape[1]), d.reshape(-1, weight.shape[0])
        dx = (d2@weight).reshape(x.shape) if ctx.needs_input_grad[0] else None
        db = d2.sum(0) if ctx.has_bias and ctx.needs_input_grad[2] else None
        dw = None
        if ctx.needs_input_grad[1]:
            _claim_backward(weight)
            state, k = ctx.state, ctx.k
            if state.sampler == 'importance':
                p = importance_probabilities(x2, d2)
                if p is None:
                    dw = torch.zeros_like(weight)
                else:
                    indices = torch.multinomial(p, k, replacement=True, generator=state.generator)
                    dw = gather_weight_gradient(x2, d2, indices, p, k)
            else:
                sx, sd = _operand_scales(x2, d2)
                if bool(sx == 0) or bool(sd == 0):
                    dw = torch.zeros_like(weight)
                else:
                    rows = torch.randint(x2.shape[0], (k,), generator=state.generator).to(x2.device)
                    xs, ds = x2.index_select(0, rows), d2.index_select(0, rows)
                    # Uniform has no per-row inverse probabilities: apply its
                    # single constant to the narrower gathered operand once.
                    scale = x2.shape[0]/k
                    dw = ds.T@(xs*scale) if xs.shape[1] <= ds.shape[1] else (ds*scale).T@xs
        for value, name in ((dx, 'dX'), (dw, 'dW'), (db, 'db')):
            if value is not None:
                _finite(value, name)
        return dx, dw, db, None, None


def sampled_linear(x: Tensor, weight: Tensor, bias: Tensor | None,
                   state: SamplingState, *, k: int | None = None) -> Tensor:
    """Native forward/exact input and bias adjoints; iid sampled dense dW.

    k defaults to max(1, ceil(rho*n)). k>=n uses native F.linear directly,
    consumes no sampler RNG, and permits native shared/tied weights. The caller
    checks native and unsampled gradients for finiteness before optimizer.step.
    """
    if any(torch.is_autocast_enabled(device) for device in ('cpu', 'cuda', 'mps')):
        raise RuntimeError('sampled_linear rejects autocast/AMP')
    if (weight.ndim != 2 or x.ndim < 1 or min(weight.shape) == 0
            or x.shape[-1] != weight.shape[1]):
        raise ValueError('incompatible linear shapes')
    n = x.numel()//weight.shape[1]
    if n == 0:
        raise ValueError('empty linear rows are unsupported')
    if weight.dtype != torch.float32 and not (weight.dtype == torch.float64 and weight.device.type == 'cpu'):
        raise ValueError('dtype must be FP32 CPU/MPS or CPU FP64 reference')
    if weight.device.type not in ('cpu', 'mps'):
        raise ValueError('device must be CPU or MPS')
    tensors = (x, weight) if bias is None else (x, weight, bias)
    if any(t.dtype != weight.dtype or t.device != weight.device for t in tensors):
        raise ValueError('linear tensors must share dtype/device')
    if bias is not None and bias.shape != (weight.shape[0],):
        raise ValueError('bias shape must match output width')
    if not isinstance(state, SamplingState):
        raise TypeError('state must be SamplingState')
    budget = max(1, math.ceil(state.rho*n)) if k is None else k
    if type(budget) is not int or budget < 1:
        raise ValueError('k must be a positive integer')
    if budget >= n:
        return F.linear(x, weight, bias)
    return _SampledLinear.apply(x, weight, bias, state, budget)


def validate_sampled_parameters(model: nn.Module, eligible_module_names: Iterable[str],
                                optimizer_parameters: Iterable[Tensor]) -> None:
    """Reject sampled aliases/views/reused modules and nonunique optimizer sets.

    Exact ties elsewhere in the model remain allowed; the optimizer must contain
    every unique model Parameter exactly once, with no additional parameters.
    """
    modules = dict(model.named_modules(remove_duplicate=False))
    names = list(eligible_module_names)
    if len(set(names)) != len(names):
        raise ValueError('sampled module names must be unique')
    all_entries = list(model.named_parameters(remove_duplicate=False))
    unique = {id(p): p for _, p in all_entries}
    optimized = list(optimizer_parameters)
    if len(optimized) != len(unique) or {id(p) for p in optimized} != set(unique):
        raise ValueError('optimizer must contain every unique model parameter exactly once')
    for name in names:
        module = modules.get(name)
        if module is None or not isinstance(module, nn.Linear):
            raise ValueError(f'sampled module {name!r} must be Linear')
        if sum(other is module for other in modules.values()) != 1:
            raise ValueError(f'sampled module {name!r} is reused/shared')
        weight = module.weight
        if sum(p is weight for _, p in all_entries) != 1:
            raise ValueError(f'sampled weight {name!r} has multiple owners/aliases')
        storage = weight.untyped_storage()
        for param in unique.values():
            if param is weight:
                continue
            if param.device == weight.device and param.untyped_storage().data_ptr() == storage.data_ptr():
                raise ValueError(f'sampled weight {name!r} has shared parameter storage/view')

@pytest.mark.parametrize('n,k', [(2, 1), (3, 1), (3, 2)])
@pytest.mark.parametrize('sampler', ['importance', 'uniform'])
def test_enumeration_unbiased_variance_duplicates(op, n, k, sampler):
    # Omitting duplicates, 1/(kp), or dividing by n breaks expectation/variance.
    x = torch.tensor([[1., 2.], [-3., .5], [2., -1.]], dtype=torch.float64)[:n]
    d = torch.tensor([[.5, -2.], [4., 1.], [-1., 3.]], dtype=torch.float64)[:n]
    # Enumeration probabilities are a separate FP64 reference, independent of
    # production FP32 score rounding. Only gather/weight/GEMM uses runtime code.
    norms = torch.linalg.vector_norm(x, dim=1)*torch.linalg.vector_norm(d, dim=1)
    p = .9*norms/norms.sum()+.1/n if sampler == 'importance' else torch.full((n,), 1/n, dtype=torch.float64)
    exact = d.T @ x
    expected = torch.zeros_like(exact)
    variance = torch.zeros_like(exact)
    duplicate_seen = False
    for rows in itertools.product(range(n), repeat=k):
        indices = torch.tensor(rows)
        estimate = op.gather_weight_gradient(x, d, indices, p, k)
        probability = math.prod(p[i].item() for i in rows)
        expected += probability * estimate
        variance += probability * (estimate - exact).square()
        duplicate_seen |= len(set(rows)) < k
    single_second = sum(torch.outer(d[i], x[i]).square() / p[i] for i in range(n))
    close(expected, exact)
    close(variance, (single_second - exact.square()) / k)
    if k > 1:
        assert duplicate_seen

def paired_ratio(dense, candidate):
    import numpy as np
    a, b = np.asarray(dense, dtype=np.float64), np.asarray(candidate, dtype=np.float64)
    if a.ndim != 1 or a.shape != b.shape or not len(a) or not np.isfinite(a).all() or not np.isfinite(b).all() or (a <= 0).any() or (b <= 0).any():
        raise ValueError('paired times must be finite, positive and equally sized')

    rng = np.random.default_rng(62001)
    draws = z[rng.integers(0, len(z), (10000, len(z)))].mean(1)
    return {'ratio': float(np.exp(z.mean())), 'ci95': np.exp(np.quantile(draws, [.025, .975], method='linear')).tolist(),

def zero_dw_linear(x, weight, bias):
    """Nonlearning optimistic diagnostic: dense zero dW, exact dX/db."""
    import torch
    from torch.nn import functional as F
    global _zero_type
    if _zero_type is None:
        class ZeroDW(torch.autograd.Function):
            @staticmethod
            def forward(ctx, x, w, b):
                ctx.save_for_backward(x, w)
                ctx.has_bias = b is not None
                return F.linear(x, w, b)

            @staticmethod
            def backward(ctx, d):
                x, w = ctx.saved_tensors
                d2 = d.reshape(-1, w.shape[0])

    def __init__(self, cfg, shape, variant='single', mode='dense', rho=.25, session=0):

        o = cfg['optimizer']
        self.opt = torch.optim.AdamW([{'params': [self.p['w1'], self.p['w2']], 'weight_decay': o['weight_decay']},
                                     {'params': [self.p['b1'], self.p['b2']], 'weight_decay': 0}],
                                    lr=o['lr'], betas=tuple(o['betas']), eps=o['eps'], **options)
        if mode in ('importance', 'uniform'):
            self.states = {k: SamplingState(self.seed, layer, mode, rho) for k, layer in
                           (('w1', 'block0.ffn_in'), ('w2', 'block0.ffn_out'))}
        self.updates = 0

    def loss(self, *, diagnostic=False):
        from torch.nn import functional as F
        from oar.sampled_linear import sampled_linear
        captured = {}
        losses = []
        for j, x in enumerate(self.x.chunk(self.s['microbatches'])):
            def linear(value, w, b):
                if self.mode == 'dense':
                    y = F.linear(value, self.p[w], self.p[b])
                elif self.mode == 'zero':
                    y = zero_dw_linear(value, self.p[w], self.p[b])
                else:
                    y = sampled_linear(value, self.p[w], self.p[b], self.states[w])
                if diagnostic:
                    y.retain_grad()
                    captured[(j, w)] = (value.detach(), y)
                return y
            y = x+linear(F.gelu(linear(x, 'w1', 'b1'), approximate='none'), 'w2', 'b2')
            losses.append(y.square().mean()/self.s['microbatches'])
        return losses, captured

    def backward(self, diagnostic=False):
        self.opt.zero_grad(set_to_none=True)
        self.x.grad = None
        losses, captured = self.loss(diagnostic=diagnostic)
        for loss in losses:
            loss.backward()
        return captured

    def step(self):
        torch = self.torch
        self.backward()
        # Native clipping checks the complete total norm before native step;
        # candidate-local probability/gradient checks are inside its backward.
        torch.nn.utils.clip_grad_norm_(list(self.p.values()), 1., error_if_nonfinite=True)
        self.opt.step()
        self.updates += 1

    def snapshot(self):
        return {'parameters': {k: v.detach().clone() for k, v in self.p.items()},
                'optimizer': copy.deepcopy(self.opt.state_dict()), 'updates': self.updates,
                'sampling': {k: v.state_dict() for k, v in self.states.items()},
                'init_state': self.init_generator.get_state().clone(), 'data_state': self.data_generator.get_state().clone()}

    def restore(self, snapshot):
        with self.torch.no_grad():
            for k, p in self.p.items():
                p.copy_(snapshot['parameters'][k])
        self.opt.load_state_dict(copy.deepcopy(snapshot['optimizer']))
        self.updates = snapshot['updates']
        for k, state in self.states.items():
            if k in snapshot['sampling']:
                state.load_state_dict(snapshot['sampling'][k])
        self.init_generator.set_state(snapshot['init_state'])
        self.data_generator.set_state(snapshot['data_state'])
        self.opt.zero_grad(set_to_none=True)
        self.x.grad = None


def primitive_qualification(cfg):
    import torch
    from oar.sampled_linear import SamplingState, sampled_linear, importance_probabilities
    rows, calibrations = [], []
    from oar.timing import measure_blocks
    for s in cfg['shapes']:
        f = Fixture(cfg, s)
        p = f.p
        # Actual shape FP32 device reduction, score-only CPU transfer,
        # FP64 CPU categorical, integer/weight transfers, gather and adjoints.
        x = f.x
        for sampler in cfg['samplers']:
            state = SamplingState(cfg['seed'], 'block0.ffn_in', sampler)
            f.opt.zero_grad(set_to_none=True)
            x.grad = None
            y = sampled_linear(x, p['w1'], p['b1'], state)
            d = torch.ones_like(y)/y.numel()
            y.backward(d)
            torch.mps.synchronize()
            torch.testing.assert_close(x.grad, d@p['w1'], rtol=1e-4, atol=1e-6)
            torch.testing.assert_close(p['b1'].grad, d.sum(0), rtol=1e-4, atol=1e-6)
            assert p['w1'].grad is not None and bool(torch.isfinite(p['w1'].grad).all())
            probabilities = importance_probabilities(x, d)
            rows.append({'shape': s, 'sampler': sampler, 'device': str(y.device), 'status': 'pass',
                         'score_count_transferred': s['n'], 'p_sum': probabilities.sum().item(),
                         'p_min': probabilities.min().item(), 'input_stride': list(x.stride())})
        f.step()  # native shader warmup only, not a performance observation
        raw = measure_blocks(f.step, torch.mps.synchronize, 3)
        calibrations.append({'shape': s, 'native_complete_step_s': raw,
                             'boundary': 'resource forecast calibration only; not comparative performance'})
        del f
    return {'operations': rows, 'native_resource_calibration': calibrations,
            'matmul_precision': torch.get_float32_matmul_precision(), 'fallback_before_import': '0'}

def native_variant_qualification(cfg, shape, session, updates):
    import torch
    from oar.timing import warmup, measure_blocks
    results, supported = {}, []
    for variant in cfg['timing']['native_variants']:
        try:
            actual, reference = Fixture(cfg, shape, variant, session=session), Fixture(cfg, shape, 'single', session=session)
            for _ in range(5):
                actual.step()
                reference.step()
                for k, p in actual.p.items():
                    torch.testing.assert_close(p, reference.p[k], rtol=1e-4, atol=1e-6)
                    for field in ('exp_avg', 'exp_avg_sq', 'step'):
                        torch.testing.assert_close(actual.opt.state[p][field], reference.opt.state[reference.p[k]][field], rtol=1e-4, atol=1e-6)
            def block():
                for _ in range(updates):
                    actual.step()
            w = warmup(block, torch.mps.synchronize, **cfg['timing']['warmup'])
            raw = measure_blocks(block, torch.mps.synchronize, 3)
            results[variant] = {'status': 'pass', 'warmup': w, 'pilot_s': raw, 'mean_s': sum(raw)/len(raw)}
            supported.append(variant)
        except (RuntimeError, NotImplementedError, AssertionError) as exc:
            results[variant] = {'status': 'unsupported', 'reason': str(exc), 'exception': type(exc).__name__}
    if not supported:
        raise RuntimeError('no qualified native AdamW variant')
    selected = min(supported, key=lambda v: results[v]['mean_s'])
    return selected, results


def timed_pairs(cfg, dense, candidate, common, updates, seed, raw_path=None):
    import torch
    from oar.timing import warmup, measure_blocks
    fixtures = {'dense': dense, 'candidate': candidate}
    sync, resets = torch.mps.synchronize, []
    def restore(f):
        start = time.perf_counter()
        f.restore(common)
        sync()
        resets.append(time.perf_counter()-start)
    def block(f):
        for _ in range(updates):
            f.step()
    warming = {}
    # Common initialization/moment history; no arm inherits another warmup.
    for name, f in fixtures.items():
        restore(f)
        warming[name] = warmup(lambda: block(f), sync, **cfg['timing']['warmup'])
    if raw_path:
        write_json(Path(raw_path).with_suffix('.warmup.json'), warming)
        Path(raw_path).open('x').close()
    rows, rng = [], random.Random(seed)
    for pair in range(cfg['timing']['pairs']):
        order = list(fixtures)
        rng.shuffle(order)
        seconds = {}
        for name in order:
            f = fixtures[name]
            restore(f)
            seconds[name] = measure_blocks(lambda: block(f), sync, 1)[0]
        row = {'pair': pair, 'order': order, 'seconds': seconds}
        rows.append(row)
        if raw_path:
            with Path(raw_path).open('a') as stream:
                stream.write(json.dumps(row)+'\n')
                stream.flush()
    return {'warmup': warming, 'pairs': rows, 'reset_s': resets, 'updates_per_block': updates,
            'order_seed': seed, 'statistics': paired_ratio([r['seconds']['dense'] for r in rows], [r['seconds']['candidate'] for r in rows])}


def state_streams(f):
    return {'init_seed': f.init_seed, 'data_seed': f.data_seed,
            'init_state': base64.b64encode(bytes(f.init_generator.get_state().tolist())).decode(),
            'data_state': base64.b64encode(bytes(f.data_generator.get_state().tolist())).decode(),
            'sampling': {k: {'seed': s.seed, 'layer_id': s.layer_id, 'sampler': s.sampler,
                            'state': base64.b64encode(bytes(s.generator.get_state().tolist())).decode()} for k, s in f.states.items()}}


def cost_session(cfg, request):
    import torch
    from oar.hardware import resource_snapshot
    from oar.sampled_linear import named_seed
    started = time.perf_counter()
    session, kind = request['session'], request['kind']
    deadline = started+request['deadline_s']
    results = {'session': session, 'kind': kind, 'start_utc': utc(), 'shapes': [], 'resources_before': resource_snapshot('mps')}
    result_path = Path(request['result'])
    def check_deadline():
        if time.perf_counter() > deadline:
            raise TimeoutError('prospectively bound complete session deadline exceeded')
    try:
        shapes = list(cfg['shapes'])
        if session % 2:
            shapes.reverse()
        for shape in shapes:
            check_deadline()
            # Available memory screening precedes shape allocation; never disable
            # the native allocator's safeguards. Observed RSS/Metal overlap.
            resource = resource_snapshot('mps')
            n, di, do = (shape[k] for k in ('n', 'di', 'do'))
            predicted = 3*64*(2*di*do+di+do)+64*n*do
            ceiling = min(.7*resource['physical_memory_bytes'], .8*torch.mps.recommended_max_memory(), resource['available_memory_bytes'])
            if predicted > ceiling:
                raise MemoryError('fixed shape does not fit conservative current memory screening')
            calibration = next(v for v in request['calibration'] if v['shape']['id'] == shape['id'])
            step_s = min(calibration['native_complete_step_s'])
            updates = max(1, min(100, math.ceil(.2/step_s)))
            # Native-only pilot can increase block length up to the fixed cap.
            pilot = Fixture(cfg, shape, session=session)
            from oar.timing import measure_blocks
            def pilot_block():
                for _ in range(updates):
                    pilot.step()
            pilot_times = measure_blocks(pilot_block, torch.mps.synchronize, 3)
            if min(pilot_times) < .2 and updates < 100:
                updates = min(100, math.ceil(updates*.2/min(pilot_times)))
            if kind == 'feasibility':
                variant, variants = native_variant_qualification(cfg, shape, session, updates)
            else:
                previous = next(v for v in request['baseline']['shapes'] if v['shape']['id'] == shape['id'])
                variant, variants = previous['selected_variant'], previous['variants']
                updates = previous['updates_per_block']
            del pilot
            dense = Fixture(cfg, shape, variant, session=session)
            for _ in range(cfg['timing']['history_updates']):
                dense.step()
            common = dense.snapshot()
            row = {'shape': shape, 'selected_variant': variant, 'variants': variants, 'updates_per_block': updates,
                   'dense_pilot_s': pilot_times, 'comparisons': {}, 'resources_before': resource,
                   'predicted_working_set_bytes': predicted, 'streams': state_streams(dense)}
            if kind == 'feasibility':
                arms = [('AA', 'dense', 1.), ('zero', 'zero', 1.)]
            else:
                arms = [(f'{sampler}-{rho}', sampler, rho) for sampler in cfg['samplers'] for rho in cfg['rhos']]
                random.Random(named_seed(cfg['seed'], 'order', kind, str(session), shape['id'], 'arms')).shuffle(arms)
            for name, mode, rho in arms:
                check_deadline()
                candidate = Fixture(cfg, shape, variant, mode, rho, session)
                comparison_common = {**common, 'sampling': {k: v.state_dict() for k, v in candidate.states.items()}}
                row['comparisons'][name] = timed_pairs(cfg, dense, candidate, comparison_common, updates,
                    named_seed(cfg['seed'], 'order', kind, str(session), shape['id'], name),
                    result_path.parent/(result_path.stem+'-'+shape['id']+'-'+name+'-pairs.jsonl'))
                row['comparisons'][name]['sampling_streams_final'] = state_streams(candidate)
                del candidate
            row['resources_after'] = resource_snapshot('mps')
            results['shapes'].append(row)
            # Persist each completed shape in its own immutable file.
            write_json(result_path.parent/(result_path.stem+'-'+shape['id']+'.json'), row)
            del dense, common
            check_deadline()
        results['status'] = 'pass'
    except (RuntimeError, TimeoutError, MemoryError) as exc:
        results.update(status='INCOMPLETE_RESOURCE' if isinstance(exc, (TimeoutError, MemoryError)) else 'INCONCLUSIVE_MEASUREMENT',
                       failure=str(exc), traceback=traceback.format_exc())
    results.update(wall_s=time.perf_counter()-started, resources_after=resource_snapshot('mps'))
    write_json(result_path, results)
    return results


def forecast_stage(cfg, calibration, kind):
    # Conservative measured native maximum; candidate components use an explicit
    # 3x allowance, with all warmup, pairs, variants, cloning and startup included.
    arms = 2 if kind == 'feasibility' else 6
    per_shape = []
    for row in calibration:
        maximum = max(row['native_complete_step_s'])
        updates = max(1, min(100, math.ceil(.2/min(row['native_complete_step_s']))))
        block = max(.2, updates*maximum)
        blocks = arms*(2*30+2*32)+(4*(32+3) if kind == 'feasibility' else 0)
        per_shape.append({'shape': row['shape']['id'], 'bound_block_s': block, 'bound_blocks': blocks,
                          'forecast_s': 3*block*blocks+128*maximum+15})
    forecast = 2*sum(r['forecast_s'] for r in per_shape)+60
    return {'kind': kind, 'sessions': 2, 'per_shape': per_shape, 'forecast_s': forecast,
            'deadline_s': 2*forecast, 'includes': 'both sessions, 3x replacement allowance, histories, warmup, reset, variants, startup and serialization',
            'diagnostic_allowance_s': 0 if kind == 'feasibility' else 300}


def offline_diagnostics(cfg, request):
    """Paid native-state information study, never consumed by timed training."""
    import torch
    from oar.sampled_linear import SamplingState, importance_probabilities, gather_weight_gradient
    from oar.timing import measure_blocks
    start = time.perf_counter()
    deadline = start+request['deadline_s']
    shape = next(s for s in cfg['shapes'] if s['id'] == 'middle4096')
    f = Fixture(cfg, shape, request['variant'])
    rows, profiles = [], []
    for target_update in cfg['diagnostic']['native_states']:
        while f.updates < target_update:
            if time.perf_counter() > deadline:
                raise TimeoutError('offline diagnostic deadline')
            f.step()
        common = f.snapshot()
        captures = f.backward(diagnostic=True)
        dense_grads = {k: p.grad.detach().clone() for k, p in f.p.items()}
        operands = {w: (x, y.grad.detach()) for (_micro, w), (x, y) in captures.items()}
        layer_info = {}
        for w, (x, d) in operands.items():
            # FP64 CPU full operands are allowed ONLY in this charged offline
            # diagnostic, never in the runtime sampler or headline timed step.
            xd, dd = x.detach().cpu().double(), d.detach().cpu().double()
            a = xd.norm(dim=1)*dd.norm(dim=1)
            exact = dd.T@xd
            norm2 = exact.square().sum().item()
            p = importance_probabilities(x, d)
            info = {'n': len(x), 'exact_norm2': norm2,
                    'heterogeneity': (len(a)*a.square().sum()/a.sum().square()).item(),
                    'score_min': a.min().item(), 'score_max': a.max().item(), 'variance': {}}
            for sampler in cfg['samplers']:
                probabilities = p if sampler == 'importance' else torch.full((len(x),), 1/len(x), dtype=torch.float64)
                for rho in cfg['rhos']:
                    k = math.ceil(rho*len(x))
                    variance = ((a.square()/probabilities).sum().item()-norm2)/k
                    info['variance'][f'{sampler}-{rho}'] = {'conditional_variance': variance,
                        'normalized_variance': variance/norm2 if norm2 else None}
            layer_info[w] = info
            profiles.append({'native_update': target_update, 'layer': w,
                'dense_dw_s': measure_blocks(lambda: d.T@x, torch.mps.synchronize, 3),
                'scores_cpu_probabilities_checks_s': measure_blocks(lambda: importance_probabilities(x, d), torch.mps.synchronize, 3),
                'note': 'separate synchronized profiles, not additive full-step observations'})
        # Native displacement/reference loss from the same committed history.
        def apply_grads(grads):
            f.restore(common)
            for key, parameter in f.p.items():
                parameter.grad = grads[key].detach().clone()
            torch.nn.utils.clip_grad_norm_(list(f.p.values()), 1., error_if_nonfinite=True)
            f.opt.step()
            return {key: parameter.detach().clone() for key, parameter in f.p.items()}
        native_parameters = apply_grads(dense_grads)
        with torch.no_grad():
            native_loss = sum(f.loss()[0]).item()
        for sampler in cfg['samplers']:
            for rho in cfg['rhos']:
                states = {w: SamplingState(cfg['seed'], 'diagnostic.'+w+'.'+str(target_update), sampler, rho) for w in operands}
                for draw in range(cfg['diagnostic']['draws']):
                    if time.perf_counter() > deadline:
                        raise TimeoutError('offline diagnostic deadline')
                    grads = dict(dense_grads)
                    errors = {}
                    for w, (x, d) in operands.items():
                        k, generator = math.ceil(rho*len(x)), states[w].generator
                        if sampler == 'importance':
                            p = importance_probabilities(x, d)
                            indices = torch.multinomial(p, k, replacement=True, generator=generator)
                            grads[w] = gather_weight_gradient(x, d, indices, p, k)
                        else:
                            indices = torch.randint(len(x), (k,), generator=generator).to(x.device)
                            grads[w] = d.index_select(0, indices).T@(x.index_select(0, indices)*(len(x)/k))
                        errors[w] = (grads[w]-dense_grads[w]).square().sum().item()/layer_info[w]['exact_norm2']
                    sampled_parameters = apply_grads(grads)
                    with torch.no_grad():
                        loss = sum(f.loss()[0]).item()
                    displacement_difference = math.sqrt(sum((sampled_parameters[w]-native_parameters[w]).square().sum().item() for w in f.p))
                    rows.append({'native_update': target_update, 'sampler': sampler, 'rho': rho, 'draw': draw,
                                 'normalized_gradient_squared_errors': errors, 'displacement_difference_l2': displacement_difference,
                                 'native_one_step_loss': native_loss, 'sampled_one_step_loss': loss, 'one_step_loss_difference': loss-native_loss})
        write_json(Path(request['attempt'])/f'diagnostic-state-{target_update}.json', {'layers': layer_info, 'rows': [r for r in rows if r['native_update'] == target_update]})
        f.restore(common)
    torch.mps.synchronize()
    return {'shape': shape, 'draws': cfg['diagnostic']['draws'], 'states': cfg['diagnostic']['native_states'], 'rows': rows,
            'profiles': profiles, 'wall_s': time.perf_counter()-start,
            'interpretation': 'offline conditional variance and copied native-AdamW one-step diagnostics; not learning success or a runtime acceptance rule'}


def hardware_stage(cfg, config, out, attempt, kind):
    bindings = source_hashes(kind)
    prepared = require_stage(out, 'prepare', bindings)
    qualification = json.loads(Path(prepared['qualification']).read_text())
    calibration = qualification['native_resource_calibration']
    baseline = None
    if kind == 'cost':
        feasibility = require_stage(out, 'feasibility', bindings)
        require_stage(out, 'correctness', bindings)
        baseline = feasibility
    forecast = forecast_stage(cfg, calibration, kind)
    if kind == 'cost':
        forecast['forecast_s'] += 300
        forecast['deadline_s'] = 2*forecast['forecast_s']
    write_json(attempt/'resource_forecast.json', forecast)
    if forecast['deadline_s'] > cfg['resources']['maximum_stage_s']:
        return {'status': 'INCOMPLETE_RESOURCE', 'reason': 'inclusive measured forecast exceeds configured stage capacity; no expensive session launched'}
    deadline = time.perf_counter()+forecast['deadline_s']
    sessions = []
    for session in range(2):
        request = {'kind': kind, 'session': session, 'config': str(config), 'out': str(out), 'attempt': str(attempt),
                   'result': str(attempt/f'session-{session+1}.json'), 'calibration': calibration,
                   'deadline_s': max(0, deadline-time.perf_counter())}
        if baseline:
            request['baseline'] = baseline['sessions'][session]
        request_path = attempt/f'session-{session+1}-request.json'
        write_json(request_path, request)
        code, _, _ = command(attempt, worker_args(kind, config, out, request_path), env=environment(cfg),
                              timeout=max(1, deadline-time.perf_counter()))
        if code or not Path(request['result']).is_file():
            return {'status': 'INCOMPLETE_RESOURCE', 'reason': 'session interrupted or deadline exceeded; retained prefix, no partial success', 'sessions': sessions}
        result = json.loads(Path(request['result']).read_text())
        sessions.append(result)
        if result['status'] != 'pass':
            return {'status': result['status'], 'reason': result.get('failure'), 'sessions': sessions}
    delta = baseline['delta'] if baseline else freeze_delta([abs(p['seconds']['dense']/p['seconds']['candidate']-1)
        for s in sessions for row in s['shapes'] for p in row['comparisons']['AA']['pairs']])
    write_json(attempt/'frozen_delta.json', {'delta': delta, 'source': 'native-only pooled two-session A/A; frozen before sampler timing', 'cap': .15})
    unstable = [(s['session'], row['shape']['id'], name) for s in sessions for row in s['shapes']
                for name, comparison in row['comparisons'].items() if not all(v['stable'] for v in comparison['warmup'].values())]
    if delta > .15 or unstable:
        return {'status': 'INCONCLUSIVE_MEASUREMENT', 'reason': 'delta above .15 or unstable warmup; evidence retained, no candidate performance qualification',
                'delta': delta, 'unstable': unstable, 'sessions': sessions}
    diagnostics = None
    if kind == 'cost':
        request = {'kind': 'diagnostic', 'config': str(config), 'out': str(out), 'attempt': str(attempt),
                   'variant': next(row for row in baseline['sessions'][0]['shapes'] if row['shape']['id'] == 'middle4096')['selected_variant'],
                   'deadline_s': max(0, deadline-time.perf_counter())}
        request_path = attempt/'diagnostic-request.json'
        write_json(request_path, request)
        code, _, _ = command(attempt, worker_args(kind, config, out, request_path), env=environment(cfg), timeout=max(1, deadline-time.perf_counter()))
        if code:
            return {'status': 'INCOMPLETE_RESOURCE', 'reason': 'paid offline diagnostic incomplete; raw session timing retained', 'sessions': sessions, 'delta': delta}
        diagnostics = str(attempt/'diagnostic.json')
    eligible = []
    names = ['zero'] if kind == 'feasibility' else [f'{s}-{r}' for s in cfg['samplers'] for r in cfg['rhos']]
    for name in names:
        for shape_id in ('middle2048', 'middle4096'):
            comparisons = [next(row for row in s['shapes'] if row['shape']['id'] == shape_id)['comparisons'][name] for s in sessions]
            if all(c['statistics']['ci95'][1] < 1-delta for c in comparisons):
                eligible.append({'arm': name, 'shape': shape_id})
    return {'status': 'pass' if eligible else 'STOP_COST', 'delta': delta, 'eligible': eligible, 'sessions': sessions,
            'diagnostics': diagnostics,
            'reason': 'upper95% paired ratio must be below 1-delta in both sessions at a planned-model middle shape',
            'zero_semantics': 'nonlearning dense zero dW with exact dX/db and native optimizer moments/decay; optimistic diagnostic, not universal lower bound'}


def correctness(cfg, config, out, attempt):
    paths = sorted((out/'prepare').glob('attempt-*/record.json'))
    prepared = read_record(paths[-1]) if paths else None
    if prepared and prepared['status'] not in ('pass', 'BLOCKED_HARDWARE'):
        raise ValueError('CPU correctness permits only qualified or hardware-blocked preparation')
    env = environment(cfg)
    code, stdout, _ = command(attempt, [sys.executable, '-m', 'pytest', '-q', 'tests/test_sampled_linear.py', 'tests/test_dw_sampling_protocol.py'], env=env)
    return {'status': 'pass' if not code else 'INCONCLUSIVE_MEASUREMENT', 'reason': 'CPU operator/protocol reference tests; actual-device qualification separately in prepare',
            'cpu_correctness_only': prepared is None or prepared['status'] != 'pass', 'test_output': stdout.strip()}

        for path in sorted((Path(out)/stage).glob('attempt-*/record.json')):
            records.append({'path': str(path), 'record_sha256': digest(path), **read_record(path)})
    terminal = next((r['status'] for r in reversed(records) if r['status'] not in ('pass', 'not_run')), None)
    if terminal is None:
        terminal = 'INCOMPLETE_RESOURCE'
    return {'schema_version': 1, 'terminal_state': terminal, 'records': records, 'primary_time_to_target': None,
            'new_performance_claim': False, 'historical_evidence': 'inherited, unchanged, separately source-attributed',
            'recommendation': 'Stop at the recorded boundary; reopening requires the unmet prerequisite and a new hash-bound prospective version.'}


def render_summary(summary):
    lines = ['<!-- SPDX-License-Identifier: CC-BY-4.0 -->', '# Bounded dW sampling report', '',
             f'Terminal state: **{summary["terminal_state"]}**.', '',
             'Fixed-budget norm-importance dW sampling and the direct-randint uniform control retain native forward, exact input/bias adjoints and native AdamW. Historical OAR results are unchanged.', '',
             'No time-to-held-out-target or endpoint language quality result exists. No corpus bodies were ingested; no trainer was added before its prerequisites.', '',
             '| Stage / attempt | State | Reason |', '| --- | --- | --- |']
    for r in summary['records']:
        lines.append(f'| {r["stage"]} / {Path(r["path"]).parent.name} | {r["status"]} | {r.get("reason", "")} |')
    lines += ['', 'Raw command exits/stdout/stderr, resource forecasts, source identities, stage records and their hashes accompany this report. Timing block intervals describe blocks, never independent training seeds.', '', summary['recommendation'], '']
    return '\n'.join(lines)

    parser.add_argument('--config', required=True, type=Path)
    parser.add_argument('--out', required=True, type=Path)

    parser.add_argument('--session-worker', type=Path, help=argparse.SUPPRESS)
    args = parser.parse_args(argv)
    cfg = load_config(args.config)
    args.config, args.out = args.config.resolve(), args.out.resolve()
    amendment = validate_amendment(args.config)
    if args.session_worker:
        request = json.loads(args.session_worker.read_text())
        if Path(request['out']) != args.out or Path(request['config']) != args.config or not args.session_worker.is_relative_to(args.out):
            raise ValueError('invalid frozen worker request')
        configure_torch()
        if request['kind'] == 'qualification':
            write_json(Path(request['attempt'])/'qualification.json', primitive_qualification(cfg))
        elif request['kind'] == 'diagnostic':
            write_json(Path(request['attempt'])/'diagnostic.json', offline_diagnostics(cfg, request))
        else:
            cost_session(cfg, request)
        return 0
    attempt = allocate_attempt(args.out, args.stage)
    start = time.perf_counter()
    identity = {'reviewed_head': REVIEWED, 'actual_head': subprocess.check_output(['git', 'rev-parse', 'HEAD'], cwd=ROOT, text=True).strip(),
                'git_status': subprocess.check_output(['git', 'status', '--porcelain'], cwd=ROOT, text=True),
                'amendment_sha256': digest(ROOT/'decisions/dw_sampling_amendment.json'), 'config_path': str(args.config),
                'measurement_hashes': source_hashes(args.stage), 'bound_files': amendment['bound_files'], 'utc': utc()}
    write_json(attempt/'source_manifest.json', identity)
    result = {}
    try:
        if args.dry_run:
            if args.stage != 'prepare':
                raise ValueError('--dry-run is prepare-only')
            result = {'status': 'not_run', 'reason': 'prepare-only dry run: validated immutable config/source/history; no device work/tests/training/downloads'}
        elif args.stage == 'prepare':
            result = prepare(cfg, args.config, args.out, attempt)
        elif args.stage in ('feasibility', 'cost'):
            result = hardware_stage(cfg, args.config, args.out, attempt, args.stage)
        elif args.stage == 'correctness':
            result = correctness(cfg, args.config, args.out, attempt)
        elif args.stage in ('pilot', 'confirm'):
            prerequisite = 'cost' if args.stage == 'pilot' else 'pilot'
            require_stage(args.out, prerequisite, source_hashes(args.stage))
            result = {'status': 'BLOCKED_ASSET', 'reason': 'WikiText license/use restriction unresolved; language infrastructure deliberately not implemented or launched'}
        else:
            summary = summarize_run(args.out)
            write_json(attempt/'summary.json', summary)
            (attempt/'report.md').write_text(render_summary(summary))
            result = {'status': 'pass', 'reason': 'incomplete/blocked summary rendered without upgrading scientific evidence', 'terminal_state': summary['terminal_state']}
    except Exception as exc:
        (attempt/'failure.txt').write_text(traceback.format_exc())
        result = {'status': 'INCOMPLETE_RESOURCE', 'reason': str(exc), 'exception': type(exc).__name__}
    record = seal_record(attempt, {'stage': args.stage, **result, 'measurement_hashes': source_hashes(args.stage),
                                  'invocation_wall_s': time.perf_counter()-start, 'source_manifest_sha256': digest(attempt/'source_manifest.json')})
    print(json.dumps({'stage': args.stage, 'status': record['status'], 'attempt': str(attempt), 'reason': record['reason']}))
    return 0 if record['status'] in ('pass', 'not_run', 'BLOCKED_ASSET', 'BLOCKED_HARDWARE', 'STOP_COST', 'INCONCLUSIVE_MEASUREMENT', 'INCOMPLETE_RESOURCE') else 1

def test_zero_dw_control_keeps_adjoint_bias_and_native_moment_decay():
    import torch
    d = driver()
    x = torch.tensor([[1., 2.]], requires_grad=True)
    w = torch.nn.Parameter(torch.tensor([[3., 4.]]))
    b = torch.nn.Parameter(torch.tensor([5.]))
    opt = torch.optim.AdamW([w, b], lr=.01, foreach=False)
    # First give the weight nonzero native history.
    w.grad = torch.ones_like(w)
    b.grad = torch.ones_like(b)
    opt.step()
    previous = opt.state[w]['exp_avg'].clone()
    opt.zero_grad(set_to_none=True)
    d.zero_dw_linear(x, w, b).sum().backward()
    torch.testing.assert_close(x.grad, w.detach())
    torch.testing.assert_close(b.grad, torch.ones_like(b))
    assert w.grad is not None
    torch.testing.assert_close(w.grad, torch.zeros_like(w))
    opt.step()
    torch.testing.assert_close(opt.state[w]['exp_avg'], .9 * previous)
    assert opt.state[w]['step'].item() == 2
